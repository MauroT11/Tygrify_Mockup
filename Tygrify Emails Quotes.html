7 customer emails and 4 staff emails. Each is built as a 600px table layout with inline styles so it holds up in Gmail, Outlook and Apple Mail. Sample data uses estimate TG-2041 from the account mockup.

Buttons link to the mockup pages for now. In the live build they become signed links into the customer's account or the admin panel.
